QRAM Module¶

Circuits (qubit architecture)¶

struct QRAMCircuit¶

Branch-based sparse simulator of the QRAM loading circuit (qubit architecture).

Uses (address, bus_input) input branches as trajectory carriers and evolves sparse SystemState along the noisy operation sequence generated by TimeStep; via good/bad branch pruning it compresses the simulation scale from all branches down to “fully simulate bad branches + one good branch as reference”.

Typical workflow:

  1. Construct the circuit and set the data tree (set_memory_random / set_memory)

  2. Optionally inject noise (set_noise_models)

  3. Sample input branches (set_input_random / set_input_uniform)

  4. Run (run_normal pruned / run_full unpruned reference)

  5. Sample the output and read the fidelity (sample_and_get_fidelity)

Circuits (qutrit architecture)¶

struct QRAMCircuit¶

Branch-based sparse simulator of the QRAM loading circuit (qutrit architecture).

Every tree node is a three-level system (qutrit): address level addr ∈ {W, L, R} and data level data ∈ {0, 1}. SubBranch trajectories are evolved along the noisy operation sequence, with support for good/bad branch pruning and output-sampling fidelity evaluation.

The typical workflow matches qram_qubit::QRAMCircuit: construct → set memory → set noise → set_input_* → run_normal / run_full → sample_and_get_fidelity.

Note

run(version) requires a non-empty noise model to be set first; for noise-free scenarios call run_normal / run_full directly (this should be handled outside QRAMCircuit).

Timing and noise scheduling¶

struct TimeStep¶

Timing and noise scheduler for the QRAM loading circuit.

Derives the routing, copy, and swap operations of each time slice from the address / data width (generate_step), and can insert noise operations after each time slice according to a noise model, producing the complete TimeSlices schedule (generate). QRAMCircuit holds a TimeStep instance internally. Also provides bad branch range (bad range) derivation: given some faulty qubit / node, it derives the address range that would load wrong data.

class QRAMFullAmp¶

Bridge from a QRAM circuit to a full-amplitude state vector (adapted only for qram_qutrit::QRAMCircuit).

The external full-amplitude simulator provides the state vector and the qubit mapping; apply decomposes the state vector into QRAM input branches (_set_branches), runs one noisy QRAM loading on the branch circuit, samples the output, and reconstructs the result back into the complete state vector (_reconstruct), thereby embedding QRAM simulation into a larger circuit evolution workflow.

Typical usage (addr qubits {0,1}, data qubits {2,3}): 

QRAMFullAmp qram(2, 2, {0,1,2,3});
qram->set_noise_models(noise);          // run(version) requires a non-null noise model
state = qram.apply(state, {0,1}, {2,3}, {}, "new");
