# 基线对比结果：QRAM-Simulator 本体 vs uniqc 线路级模拟

同一个 QRAM 装载任务（qubit 架构，2 层树 = 地址 2 比特，数据 1 比特，memory=[0,1,1,0]，
输入 = 地址均匀叠加、bus=0），同一套噪声（**只加在 QRAM 路由树上**，地址寄存器和 bus 不加噪；
噪声参数 = 每个时间步、每个活跃树位置的信道概率），两套模拟器各跑一遍：

- **QRAM-Simulator 本体**：C++ 稀疏轨迹引擎（Python 绑定驱动）。噪声靠随机采样，
  每次 `run_full` 是一条噪声轨迹，跑 500 条取平均 → 结果带蒙特卡洛统计误差；
- **uniqc 线路级模拟**：把同一个装载线路逐门展开成量子线路（门序列直接取自 C++ 的
  TimeStep 调度器），噪声作为信道在密度矩阵上精确演化 → 精确值，无统计误差。

复现命令：`python -m qram_simulator.baseline.compare --addr 2 --runs 500 --seed 20260925`（qram-simulator 0.2.2.dev0）。

## 每列是什么

| 列 | 含义 |
|---|---|
| p / γ | 噪声参数：去极化概率 p，或振幅阻尼概率 γ |
| QRAM F（±误差） | QRAM-Simulator 的装载保真度：500 条轨迹的 F=‖⟨ψ理想\|ψ轨迹⟩‖² 平均，± 为蒙特卡洛标准误 |
| uniqc F | uniqc 密度矩阵的同一保真度：F=⟨ψ理想\|ρ\|ψ理想⟩（与左列同一口径的精确值） |
| 差值 | 两列之差；小于 3×蒙特卡洛误差即统计一致（"✓"） |
| F_cls | 两侧输出分布（地址,bus 联合分布）的经典保真度 (Σ√pq)²，各自归一化后比较，1=完全一致 |
| TVD | 同上分布的总变差距离，0=完全一致 |
| survival / trace | 振幅阻尼下的存活概率：QRAM 侧=各轨迹范数平方之和的平均，uniqc 侧=trace(ρ)，两者应相等 |

"理想态"指装载完全成功的末态：每个地址分支上 bus = 输入 bus XOR memory[地址]，QRAM 树回到基态。

## 无噪对照

不加噪声时，两侧输出分布逐位相等，最大差 5.6e-17（机器精度）——因为线路级这一侧的
门序列就是从 C++ TimeStep 调度器读出来的，两侧本来就是同一个线路。

## 结论

1. **保真度**：所有噪声强度下（含 6 组混合）uniqc 的精确值都落在 QRAM-Simulator 蒙特卡洛误差带内
   （"一致"列全 ✓）——密度矩阵信道系综 = 轨迹系综的平均，两套模拟器互相印证。
2. **输出分布**：F_cls ≥ 0.999、TVD ≤ 0.026（与轨迹条数相应的统计涨落量级）。
3. **存活概率**：阻尼下 trace(ρ) 与轨迹 survival 吻合（γ=0.2 时差 0.008）。

补充一句（不影响上表）：uniqc 侧的阻尼信道必须按 QRAM-Simulator 的采样方案逐条对应
（每步整树 K0 + 活跃位置上的跳变，权重取当前激发布居）；若换成教科书标准的
trace-保持振幅阻尼信道，γ=0.2 时分布保真度会掉到 0.76——可用
`--modes faithful textbook` 自行复现这个对照。
