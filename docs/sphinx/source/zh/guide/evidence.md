# 深度20四信道证据复算（任务2.1）

固定的任务2.1材料——**20 层树、1,048,576 条种子随机数据记录、四个噪声信道**
（BitFlip / PhaseFlip / Depolarizing / Damping）作用于同一输入——以标准产品入口
发布，而非仓库内部脚本。每个信道与概率点消费同一份数据摘要与同一个 16 地址
相干叠加输入。

```bash
qram-simulator evidence                       # 打印 summary JSON
qram-simulator evidence --outdir records/     # 另写逐轮原始 JSON
qram-simulator evidence --out summary.json
python tools/depth20_four_channel.py --outdir build-evidence   # 仓库侧包装
```

GUI 以**任务2.1 四信道证据复算**面板提供同一复算（默认配置在笔记本 CPU 上
约一到三分钟，300 秒时限，可下载 JSON）。面板与 CLI 调用同一打包模块
`qram_simulator.evidence`；普通用户不接触原生内部依赖。

## 配置

| 参数 | 默认 | 含义 |
|---|---|---|
| `--trajectories` | 2048 | 每个信道点的 Monte-Carlo 轨迹数（记录值 2048） |
| `--stress-trajectories` | 256 | 相位翻转压力点轨迹数 |
| `--stress-probability` | 1e-4 | 相位翻转压力概率（空位模型校准点） |
| `--linearity-probability` | 4e-6 | X 型线性点（阻尼固定用 2e-6） |
| `--seed` | 20261109 | 数据、输入叠加与每条轨迹的种子 |

核心由记录材料固定、不作为旋钮：深度 20、一位数据、16 个叠加输入地址、四个
信道在 p=1e-6。默认种子下复算会校验数据摘要等于记录值
`77a36d821e367599b802a0969566f6507f7299dc4888e72b6fbe7b2cafe5a767`
（与 v0.3.0 记录一致），不一致即报错。

## 十六项理论锚点

summary（`qramsim.depth20-four-channel.v1`）内嵌种子、逐轨迹样本、数据摘要、
理论公式与版本来源，并评估十六项显式同深度锚点：

1. **无噪声恒等**——幺正保迹的装载使全线路与逻辑查询保真度恒为 1；
2. **相位翻转空位模型**——Z 打击只在激发位置起效；在压力概率处校准有效
   激发路线规模，在 p=1e-6 处*预测*（而非拟合）跌落比例与平均亏损，并在
   Poisson 容差内验证；
3. **X 型残差塌缩**——闲置位置上的 X 打击不会被逆计算，全线路重叠塌缩而
   偏迹路由树的逻辑保真度显著更高；
4. **一阶 Pauli 组合与线性**——退极化亏损由 2/3 的 X 型翻转损伤与 2/3 的
   Z/Y 相位跌落贡献组成，亏损对 p 线性；
5. **阻尼 K0 占据尺度**——整树联合阻尼亏损保持在文档化的 O(深度 × 路由
   窗口) 调度尺度；
6. **归一化**——每条轨迹迹误差 < 1e-9。

采样型锚点（压力衰减、单调性、空位预测窗口、阻尼占据尺度）按记录的
2048 轨迹配置校准；降低轨迹数可能诚实地使个别采样锚点失败——更少的样本
看到更少的稀有跃迁事件。无噪声恒等、摘要、X 型塌缩与归一化锚点在任意
规模下都是确定性的。

## 范围

单一代表性种子输入，非穷尽输入证明；每个观测量 95% 边缘 Monte-Carlo 区间，
不声明统一置信度证书；不是硬件运行也不是验收证书。历史 summary 永不修改
——模型变更时重新计算产生新工件并保留旧工件。
