{# Language switcher: maps the current page to its counterpart in the other language tree. Both trees are built by SEPARATE sphinx-build runs (zh/ and en/) and merged one level below the site root, so the other tree is not a document of the current build — pathto() cannot reach it. Emit the link by hand instead: depth of the page below the site root is len(pagename segments) + 1, giving (pagename.count('/') + 1) `../` hops from the page's own directory.
