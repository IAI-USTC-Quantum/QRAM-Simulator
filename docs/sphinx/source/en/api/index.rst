API Reference
=============

.. toctree::

   cpp

The API of the Python bindings (the ``qram_simulator`` package) is built automatically
by sphinx-autoapi from the type stubs generated by pybind11-stubgen; see the
"api/python" section in the sidebar of the online site. The docstrings come from the
same source (Doxygen) as the C++ comments on this page; for the complete original
comments you can also read the repository's header files directly:

- ``QRAM/include/`` — the two QRAM circuit and branch structure families
- ``Common/include/`` — infrastructure such as the full-amplitude bridge, the random engine, matrices, and logging
