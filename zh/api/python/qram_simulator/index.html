qram_simulator¶

qram_simulator -- Python bindings for the QRAM-Simulator C++ core.

Exports QRAMCircuit for both QRAM architectures (qubit / qutrit), the full-amplitude bridge QRAMFullAmp, the timing & noise scheduler TimeStep, and global random-seed control. See the _core module docstring and the project documentation for details.

Enum of QRAM operation types.

Noise members (BitFlip / PhaseFlip / BitPhaseFlip / Depolarizing / Damping, etc.) take occurrence probabilities in [0, 1]; Damping additionally requires gamma < 1 (gamma = 1 decays all excitations within a single step, breaking sampling and normalization).

class qram_simulator.QRAMCircuitQubit(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex)¶
class qram_simulator.QRAMCircuitQubit(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex, memory: collections.abc.Sequence[SupportsInt | SupportsIndex])

Branch-based sparse simulator of the qubit-architecture QRAM loading circuit.

Carries (address, bus_input) input branches as trajectories, evolves the sparse SystemState along the noisy operation sequence generated by TimeStep, and supports good/bad branch pruning (run_normal), the unpruned reference (run_full), and fidelity sampling.

Typical workflow:

qram = QRAMCircuitQubit(addr_size, data_size[, memory]) qram.set_noise_models({...}) # optional qram.set_input_uniform(n) # or set_input_random(n) qram.run_normal() # or run_full() / run("normal") qram.sample_and_get_fidelity()

Construct the QRAM circuit initialized with the given memory (memory length must be 2^addr_size).

get_fidelity() → float¶

Alias of sample_and_get_fidelity.

get_fidelity_conventions() → dict¶

Return the three no-post-selection fidelity statistics of the current run as a dict (call after run_full, before sample_and_get_fidelity):

overlap_fid: |<psi_ideal|psi_traj>|^2, tree-sensitive -- statistically

matches the channel-level <psi_ideal|rho|psi_ideal> of the baseline;

fid_nopost: same inner product but tree-insensitive (bus-correct

amplitudes with residual tree excitations still counted);

fid_incoh: incoherent (branch-projected) combination of the same.

class qram_simulator.QRAMCircuitQutrit(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex, memory: collections.abc.Sequence[SupportsInt | SupportsIndex])

Branch-based sparse simulator of the qutrit-architecture QRAM loading circuit.

Each tree node is a three-level system (addr ∈ {W, L, R}, data), evolved along the noisy operation sequence via SubBranch trajectories. The workflow matches QRAMCircuitQubit: construct -> set memory -> set noise -> set_input_* -> run_normal/run_full -> sample_and_get_fidelity.

class qram_simulator.QRAMFullAmp(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex, memory: collections.abc.Sequence[SupportsInt | SupportsIndex])¶

Bridge from the QRAM circuit to a full-amplitude state vector (qutrit architecture only).

An external full-amplitude simulator (or a user script) supplies the state vector and qubit mapping; apply composites one QRAM loading onto that state vector and returns the new vector, embedding QRAM simulation into a larger circuit-evolution pipeline.

示例

manipulator = QRAMFullAmp(2, 2, [0, 1, 2, 3]) manipulator.set_noise_models({OperationType.Depolarizing: 1e-3}) out = manipulator.apply(state, [0, 1], [2, 3], [], version="normal")

Construct the bridge: internally creates a qutrit QRAMCircuit loaded with the given memory.

apply(state: collections.abc.Sequence[complex | SupportsComplex | SupportsFloat | SupportsIndex], address_qubits: collections.abc.Sequence[SupportsInt | SupportsIndex], data_qubits: collections.abc.Sequence[SupportsInt | SupportsIndex], other_qubits: collections.abc.Sequence[SupportsInt | SupportsIndex], version: str = 'normal') → list[complex]¶

Composite one QRAM loading onto a full-amplitude state vector.

参数:

  • state -- list of complex amplitudes (length 2^total qubit count)

  • other_qubits (address_qubits / data_qubits /) -- indices of the three qubit groups

  • version -- "normal" (pruned) or "full" (unpruned)

返回:

the new state vector after loading (list of complex numbers)

class qram_simulator.TimeStep(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex)¶

Timing and noise scheduler for the QRAM loading circuit.

Derives the routing, copy, and swap operations of each time slice from the address / data widths, and can insert noise operations after every time slice according to the noise models, producing the complete TimeSlices schedule. QRAMCircuit holds a TimeStep instance internally and calls generate in initialize_system to produce the noisy operation sequence.

Construct the scheduler.

参数:

  • addr_size -- address width

  • data_size -- data width
