qram_simulator
==============

.. py:module:: qram_simulator

.. autoapi-nested-parse::

   qram_simulator -- Python bindings for the QRAM-Simulator C++ core.

   Exports QRAMCircuit for both QRAM architectures (qubit / qutrit), the
   full-amplitude bridge QRAMFullAmp, the timing & noise scheduler TimeStep,
   and global random-seed control. See the ``_core`` module docstring and
   the project documentation for details.

.. py:class:: OperationType(value: SupportsInt | SupportsIndex)

   Enum of QRAM operation types.

   Serves both as the key type of noise models (dict keys of
   set_noise_models) and as the type tag of an Operation. Noise members
   (BitFlip / PhaseFlip / BitPhaseFlip / Depolarizing / Damping, etc.) take
   occurrence probabilities in [0, 1]; Damping additionally requires
   gamma < 1 (gamma = 1 decays all excitations within a single step,
   breaking sampling and normalization).

.. py:class:: QRAMCircuitQubit(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex)
              QRAMCircuitQubit(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex, memory: collections.abc.Sequence[SupportsInt | SupportsIndex])

   Branch-based sparse simulator of the qubit-architecture QRAM loading circuit.

   Carries (address, bus_input) input branches as trajectories, evolves the
   sparse SystemState along the noisy operation sequence generated by
   TimeStep, and supports good/bad branch pruning (run_normal), the
   unpruned reference (run_full), and fidelity sampling.

   Typical workflow:
       qram = QRAMCircuitQubit(addr_size, data_size[, memory])
       qram.set_noise_models({...})       # optional
       qram.set_input_uniform(n)          # or set_input_random(n)
       qram.run_normal()                  # or run_full() / run("normal")
       qram.sample_and_get_fidelity()

   Construct the QRAM circuit initialized with the given memory (memory length must be 2^addr_size).


   .. py:method:: get_fidelity() -> float

      Alias of sample_and_get_fidelity.



   .. py:method:: get_fidelity_conventions() -> dict

      Return the three no-post-selection fidelity statistics of the current
      run as a dict (call after run_full, before sample_and_get_fidelity):

        overlap_fid: |<psi_ideal|psi_traj>|^2, tree-sensitive -- statistically
          matches the channel-level <psi_ideal|rho|psi_ideal> of the baseline;
        fid_nopost: same inner product but tree-insensitive (bus-correct
          amplitudes with residual tree excitations still counted);
        fid_incoh: incoherent (branch-projected) combination of the same.



   .. py:method:: get_memory() -> list[int]

      Return the data tree (reference view).



   .. py:method:: get_noise_models() -> dict[OperationType, float]

   .. py:method:: get_output_distribution() -> dict[str, float]

      Return the marginal (address:bus) output distribution of the current

.. py:class:: QRAMFullAmp(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex, memory: collections.abc.Sequence[SupportsInt | SupportsIndex])

   Bridge from the QRAM circuit to a full-amplitude state vector (qutrit
   architecture only).

   An external full-amplitude simulator (or a user script) supplies the
   state vector and qubit mapping; apply composites one QRAM loading onto
   that state vector and returns the new vector, embedding QRAM simulation
   into a larger circuit-evolution pipeline.

   .. rubric:: 示例

   manipulator = QRAMFullAmp(2, 2, [0, 1, 2, 3])
   manipulator.set_noise_models({OperationType.Depolarizing: 1e-3})
   out = manipulator.apply(state, [0, 1], [2, 3], [], version="normal")

   Construct the bridge: internally creates a qutrit QRAMCircuit loaded with the given memory.


   .. py:method:: apply(state: collections.abc.Sequence[complex | SupportsComplex | SupportsFloat | SupportsIndex], address_qubits: collections.abc.Sequence[SupportsInt | SupportsIndex], data_qubits: collections.abc.Sequence[SupportsInt | SupportsIndex], other_qubits: collections.abc.Sequence[SupportsInt | SupportsIndex], version: str = 'normal') -> list[complex]

      Composite one QRAM loading onto a full-amplitude state vector.

      :param state: list of complex amplitudes (length 2^total qubit count)
      :param address_qubits / data_qubits / other_qubits: indices of the three qubit groups
      :param version: "normal" (pruned) or "full" (unpruned)

      :returns: the new state vector after loading (list of complex numbers)

.. py:class:: TimeStep(addr_size: SupportsInt | SupportsIndex, data_size: SupportsInt | SupportsIndex)

   Timing and noise scheduler for the QRAM loading circuit.

   Derives the routing, copy, and swap operations of each time slice from
   the address / data widths, and can insert noise operations after every
   time slice according to the noise models, producing the complete
   TimeSlices schedule. QRAMCircuit holds a TimeStep instance internally
   and calls generate in initialize_system to produce the noisy operation
   sequence.

   Construct the scheduler.

   :param addr_size: address width
   :param data_size: data width


   .. py:method:: full_step() -> int

      Total number of time slices of the full loading procedure.



   .. py:method:: generate(noises: collections.abc.Mapping[OperationType, SupportsFloat | SupportsIndex], arch_type: SupportsInt | SupportsIndex) -> TimeSlices

      Generate the noisy schedule.

      :param noises: noise models, a {OperationType: probability} dict (may be empty)
      :param arch_type: architecture constant, ARCH_QUBIT or ARCH_QUTRIT



   .. py:method:: generate_step(step: SupportsInt | SupportsIndex) -> OperationPack

      Maximum number of tree layers entangled at the given time slice.

      Position-sampled noise of that slice lives on the tree positions
